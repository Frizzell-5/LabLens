Getting started

Open Serpentine and wait for the status at the top right to read Python ready. The app opens with an example loaded so you can see a finished analysis right away.

The left column has four numbered steps: Analysis, Data, Settings and Style. Work through them in order the first time; after that, jump to any step. The right side shows your figures, results and tables, and updates as you go.

Press Try example on any analysis to load sample data for it. It's the quickest way to learn what each setting does.

Choosing an analysis

If your question is…Use
Do these groups differ?Compare groups. Control vs treatment, several doses, genotypes, before vs after in the same subjects.
How did a signal change after an event?Time course around an event. Breathing, heart rate, blood pressure, temperature, activity or any recording with a time column.
Does one measure track another?Correlation & regression.
How potent is this compound?Dose-response curve.

Adding data

In the Data step, either press Paste a new table and paste into the box, press ⌘V / Ctrl+V anywhere on the page, or drop files onto the dashed area. CSV, TSV, TXT and Excel files work. Each Excel sheet becomes its own table.

Put column names in the first row. Serpentine shows how it read your table underneath, labelling each column as number, time or text, so you can check it before going on.

Compare groups: two layouts

One column per group (like Prism's column tables):

Vehicle   Drug 10 mg/kg   Drug 30 mg/kg

Values plus a group column (tidy format, common in exported data):

From LabChart

In LabChart, select the rows of your Data Pad, copy them, and paste into Serpentine. Time columns written as 8:40 or 0:08:40 are read as clock times automatically.

Time-course sessions

For a time course, add one table per recording session. Every session needs the same column names. A sessions sheet then appears in the Data step, where you fill in four things for each one:

FieldWhat to enterExample
GroupThe condition this session belongs to.Morphine
SubjectThe animal or participant. Used to pair sessions from the same subject.M101
EventWhen the injection or stimulus happened, in recording time. Use mm:ss, h:mm:ss or seconds.13:27
ExcludeTime ranges to drop, such as a loose wire or movement. Separate several ranges with commas.8:00-8:50, 21:10-22:00

In Settings, choose the measurement, the bin size, the baseline window (for example −5 to 0 min), how to express values (% of baseline, change from baseline, fold, or raw) and the endpoint window that gets tested. A quality column filter lets you keep only rows that pass a check, for example a cycle count of at least 10.

Turn on Pair sessions by subject when the same animals were recorded under each condition, so Serpentine uses a paired test.

How tests are chosen

With Test: Automatic, Serpentine checks each group with the Shapiro-Wilk test. If every group looks normal it uses a parametric test, otherwise a rank-based one. You can force either choice.

DesignParametricNon-parametric
2 groupsWelch's t-test (or Student's)Mann-Whitney U
2 pairedPaired t-testWilcoxon signed-rank
3+ groupsOne-way ANOVA + Tukey or DunnettKruskal-Wallis + Holm-corrected Mann-Whitney
3+ pairedRepeated-measures ANOVA + Holm-corrected paired tFriedman + Holm-corrected Wilcoxon

Effect sizes (Hedges' g or Cohen's dz) are reported for two-group tests. Groups with fewer than five values trigger a reminder to show individual points and interpret p-values carefully.

Styling figures

The Style step has everything you would otherwise do in matplotlib, in collapsible sections. Start with a quick style (Clean, Journal, Classic, Minimal, Editorial, Boxed, Typewriter, Soft, Poster, Slides, Neon or Sketch), then change anything:

  • Plot type: bar, scatter dot, mean ± error, box, violin, box + violin, raincloud, beeswarm, strip or lollipop, vertical or horizontal, with adjustable widths, point spread, fill and outline.
  • Groups: rename any group and give it its own color, marker, hatch pattern and line style.
  • Colors: palettes, any matplotlib colormap (reversible), your own hex codes, and separate figure, plot-area and text colors.
  • Points, lines and error bars: marker shape, size, opacity and outline; line and axis widths; SEM, SD or 95% CI, two-sided or outward, with any cap width.
  • Text: twelve fonts, separate sizes for title, axis labels and ticks, bold options, title position, label angle and a panel letter.
  • Axes: choose each axis line, offset and trim them, tick direction, length and spacing, minor ticks, decimal places, limits and log scales.
  • Grid, reference lines and legend: gridline direction and style; lines such as y=100: Baseline; x=0; legend position, columns, frame and title.
  • Size: width and height in inches with millimetres shown. Journal style fits a single 89 mm column.

Plain-English commands

Above your figure is a command bar. Type what you want and press Enter, for example remove gridlines, make Saline navy and Morphine coral, horizontal violin plot, y axis from 0 to 1000 or title Day 21. Combine several with “and” or commas. Serpentine shows exactly what it changed, and What can I say? lists the kinds of commands it understands. It runs on your computer, so it's instant and private. Press ↑ to bring back an earlier command.

Your own styles

Name the current look and press Save style to reuse it in any project. Export style file saves it as a file that colleagues can import, so a lab can share one house style.

Advanced: Python

The last section accepts matplotlib settings (one key: value per line) and your own Python code, which runs on each figure with fig, ax, plt, np and pd ready. For example ax.set_yticks([0, 50, 100]). Errors appear as notes instead of breaking the figure, and your code is included in the downloaded Python script.

Changed your mind? Undo and Redo (⌘Z / ⇧⌘Z) step back through every setting.

Exporting results

  • Figures: PNG, SVG and PDF buttons on each figure, with TIFF, JPG and EPS under More. Copy puts the figure on your clipboard for slides and documents. Set resolution and a transparent background in Style.
  • Tables: Copy for Excel puts a table on your clipboard to paste into Excel or Prism; CSV downloads it.
  • Methods text: a paragraph describing what was done. Treat it as a draft and check it against your protocol.
  • Python script: a single file that reproduces the analysis. Run it with pip install numpy scipy pandas matplotlib then python script.py.

Saving projects

Serpentine keeps your latest work in the browser automatically. To keep it for good, press Save (or ⌘S / Ctrl+S) to download a .serpentine.json file with your data and every setting. Open loads it again on any computer.

Troubleshooting

  • Stuck on “Starting Python”. Serpentine needs an internet connection to load the Python engine the first time. Check your connection and reload.
  • A column reads as text. Usually a stray word or unit inside the numbers. Fix the cell, or delete the units row.
  • “Couldn't read the time”. Write event and exclusion times as 13:27, 0:13:27 or plain seconds like 807.
  • The downloaded copy shows a blank page. Start it with the launcher file rather than opening app.html directly, because browsers block the Python engine on pages opened from disk.
FAQ

Questions

Is my data uploaded anywhere?

No. Serpentine downloads the Python engine to your browser, and all parsing, statistics and drawing happen on your computer. Your tables are never sent to a server. Your latest project is kept in your browser's local storage so it's there when you come back.

Is it free?

Yes. Serpentine is free to use, online or downloaded.

Can I trust the statistics?

Serpentine uses SciPy, the standard open scientific library behind much of published research, for every test, and it reports exactly which test was used. You can also download the Python script and check every step. As with any software, choose an analysis that matches your experimental design.

Will my figures look like everyone else's?

Only if you want them to. Every visual property is a setting, from fonts and axis lines to per-group markers and hatch patterns, and the optional Python box lets you do anything matplotlib can. Save your look as a style so your figures stay recognisably yours.

Does it replace GraphPad Prism?

For the analyses it covers, it can. Serpentine focuses on things Prism handles less well: event-aligned recordings, fully customizable modern plot types such as raincloud and beeswarm plots, reproducible scripts and keeping data local. Prism still covers many more analyses today.

How do I cite Serpentine?

The methods text names Serpentine and the versions of Python, NumPy, SciPy, pandas and matplotlib used. Cite the software by name and link to github.com/Frizzell-5/Serpentine.

Can I suggest a feature or report a bug?

Yes. Open an issue on GitHub. Multi-panel figures, survival curves, two-way ANOVA and direct LabChart file import are already on the roadmap.
